# 声音与磁场基线复核和改进（2026-10-29）

1．声音侧：BEATs 是强骨干，但“冻结 BEATs＋简单打分”不能直接称为任务 SOTA。本次核实的 DCASE2026 冠军是完整 NA-BEATs 任务适配与集成系统，官方分数70.24。这与本项目七类开发集评测范围不同，不能直接相减作为可实现的增益。

发现并更正了历史域 AUROC 口径：官方使用该域正常声与两个域的全部异常声。不改变模型输出，重算得到 BEATs 60.61%、NA-BEATs 62.62%，差值+2.01个百分点，条件成对95%区间[+0.12, +3.94]。这一更正不影响声音分类或问答成绩。

作者统一开发集协议下，原BEATs为61.32，NA-BEATs为63.92，判别适配后的NA-BEATs为64.57；对应NA-EAT为64.20、NA-Dasheng为63.10。因此目前有证据的优先级是补足正常库分数重缩放、判别适配和多种子集成，而非直接换更大编码器。上述数字来自论文，并非本轮新增推理结果。[官方结果](https://dcase.community/challenge2026/task-first-shot-unsupervised-anomalous-sound-detection-for-machine-condition-monitoring-results)、[统一协议论文](https://arxiv.org/html/2608.00447v2)。

2．磁场侧：沿用相同3177窗口和44设备日，完成16种新增配置。所有外层日期与设备隔离；嵌套选参仅使用外层训练集。以下macro-F1先按设备汇总OOF，再对三台设备等权平均。

| 方法 | 同设备留日 | 严格留设备 |
| --- | ---: | ---: |
| FISHER＋原固定线性头 | 0.7332 | 0.3133 |
| FISHER＋训练内选头 | 0.7434 | 0.3289 |
| MantisV2＋原固定线性头 | 0.5377 | 0.3396 |
| MantisV2＋训练内选头 | 0.6167 | 0.3206 |
| TSPulse＋原固定线性头 | 0.4170 | 0.2713 |
| TSPulse＋训练内选头 | 0.4981 | 0.2973 |

| MiniRocket归一化频带时序 | 0.5301 | 0.3116 |
| 训练内自动选择表征和分类头 | 0.7614 | 0.3579 |

ExtraTrees相对原FISHER的留日增益为+0.0670，条件成对95%区间[+0.0470, +0.0892]。说明当前设备内任务上，更合适的监督分类方法有实际价值。ExtraTrees并非预训练基座。

自动选择方案相对原MantisV2的留设备增益为+0.0183，条件成对95%区间[+0.0022, +0.0348]。区间未跨零，但仍是既有三台设备上的探索性证据。

改分类头并非总能改善跨设备：Mantis单模型的嵌套选头结果就没有超过原固定头。本轮不能据分类头收益宣称磁场预训练知识成立；匹配随机骨干的结果与区间已保留。

其他方法方面，本轮实际复现了MiniRocket和ExtraTrees；MultiRocket/HYDRA、源设备自监督TS2Vec、小型TCN/InceptionTime值得作为后续对照。TiViT和TS2Vec-FM等通用时序候选也应以相同划分验证，其公开时序榜单成绩不能当作本项目磁场成绩，TS2Vec-FM权重可下载性本轮尚未核实。

当前更大瓶颈仍是跨设备工况、安装／幅值和特征分布差异；这些是与现象一致的解释，本轮不能独立分离其因果作用。原始时钟、日志同步、独立回合溯源和0–100Hz缓存的限制未修复。建议新增已核验日期、运行回合和工况，再确认方法增益；若允许一天标注校准，应单列评测，不要与完全未见目标设备混用。

本轮为已看过旧测试结果后的探索性重评测。区间以日期为分组、条件于已拟合模型，未校正全部多重比较，不代表硬件总体置信区间。完整数字、逐类召回、选择审计与复核在[英文报告](REPORT.md)和[指标](summary.json)。
